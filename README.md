# 💻 Laptop Inventory System

A web-based **Laptop Inventory System** built using **Java, Spring Boot, Thymeleaf, and MySQL**.  
The application helps manage laptop records, track availability, and maintain product details through a clean, user-friendly interface.

---

## 🚀 Features

- View available laptops  
- Add new laptops  
- Update laptop information  
- Delete records  
- Track availability status  
- Responsive UI with Thymeleaf  
- Persistent storage using MySQL  

---

## 🛠️ Tech Stack

**Backend:** Java, Spring Boot, Spring MVC, Spring Data JPA  
**Frontend:** Thymeleaf, HTML, CSS, Bootstrap  
**Database:** MySQL  
**Build Tool:** Maven
